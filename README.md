🖼️ Task 1: AI-Powered Image Captioning

An AI-powered web application that generates meaningful captions for uploaded images using Computer Vision and Natural Language Processing.

✨ Features

Image Upload: Upload images through an interactive web interface.  
AI Caption Generation: Generates descriptive captions for uploaded images.  
Computer Vision: Processes and analyzes visual information from images.  
Web Application: Responsive interface with a FastAPI backend.  
Deployment Support: Includes Docker configuration for application deployment.

🛠️ Tech Stack

Python 3.x  
FastAPI  
Uvicorn  
Computer Vision  
Natural Language Processing  
Deep Learning  
HTML / CSS  
Docker

🏃 How to Run

👤 Task 3: Face Detection & Recognition

A real-time computer vision application that detects faces through a webcam and recognizes registered faces using OpenCV-based face detection and recognition models.

✨ Features

Real-Time Face Detection: Detects faces through a live webcam feed.  
Face Recognition: Identifies registered faces from the known faces dataset.  
Unknown Face Detection: Detects and labels faces that are not registered.  
Live Status: Displays detected, recognized, and unknown face counts.  
Known Face Management: Supports loading registered face data.  
Web Dashboard: Provides a browser-based interface for real-time monitoring.

🛠️ Tech Stack

Python 3.x  
OpenCV  
YuNet  
SFace  
Flask  
NumPy  
HTML / CSS

🏃 How to Run

cd Task3_Face_Detection_and_Recognition  
pip install -r requirements.txt  
python3 app.py

Then open:

http://127.0.0.1:5000
